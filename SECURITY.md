# Security

## Reporting a problem

If you find a security or privacy problem in Companion for YouTube, please
report it privately first:

- **GitHub:** open a private report from this repository's **Security** tab
  (**Report a vulnerability**).

Say what you found, how to reproduce it, and which version you use (Settings
shows it at the bottom). Please don't open a public issue for it until a fix
is out.

## What counts

- Anything that lets a web page, including youtube.com, read or change the
  extension's data or settings.
- Anything that sends data somewhere other than what [PRIVACY.md](PRIVACY.md)
  lists.
- A backup file that can do more than restore channels and settings.

A bug that only breaks a feature, with no data exposed, is a normal issue.

## Supported versions

Only the latest version in the Chrome Web Store and Edge Add-ons gets fixes.
